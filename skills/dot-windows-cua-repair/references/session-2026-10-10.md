## 修改文件与回滚

当时修改的入口为 `@oai/cua-repl/bin/cua-repl.mjs`；启动模块为 `dist/lib/js/oai_js_cua_repl/src/launch.js`；新增 `windows-cwd-bridge.mjs` 与 `read-parent-browser-env.py`。第三、四项由固定的本机 Python/psutil 检查父进程，依赖该 Python 和记录的 Codex core 路径。

原维修目录保留入口原版、各阶段入口、启动模块原版、辅助脚本、启动测试、change-record.json 和 Restore.ps1。临时 browser-service 计时插桩已恢复原始哈希，不属于长期修复；原 Restore.ps1 本身不负责计时文件。新的 Skill 安装器使用独立的 manifest 事务，不能把两种回滚格式混用。

本包将入口和父信息读取整理为参数化实现；cwd 桥另补了“没有 MXC 元数据的 JS 已运行后也不能搬目录”的防护。因此这是基于实测方案的可复用整理版，**没有在整理时覆盖本机已运行的手工修复**。公开版保留原始版本指纹；离线测试改用独立合成样例，不分发厂商原始入口/模块。没有打包 app.asar 提取内容、完整日志、凭证或身份值。
