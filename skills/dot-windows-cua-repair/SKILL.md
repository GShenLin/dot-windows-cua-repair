# dot-windows-cua-repair

按与 2026-10-10 本次故障相同的 Windows Codex / 本地执行器场景，**一次完成适用的四层环境修复、条件注册修复和本机验证**。原四层已有用户转述 Dot 成功反馈；新增 node_repl 注册修复已通过本机发现与工具列表检查，未验证原 Dot 任务最终工具目录。两者的验证范围分开记录。

**执行本 Skill 不需要 Dot 配合、确认或回传。** 历史上的逐层试错只解释根因，不是新的使用流程。使用者要求修复后，直接完成本机检查、整套安装、启动验证和收尾，不发送“请让 Dot 再试一次”，不把外部反馈列为完成条件。

## 根据任务读取

- 开始排错：读 [诊断与决策](references/diagnosis.md)，区分对话恢复、启动、路由、网页检查和桌面权限。
- 执行脚本：读 [脚本操作与回滚](references/scripts.md)。默认诊断/预览，修改需显式 `--apply`；用户已要求修复时可在其范围内直接执行，不重复索取授权。
- 追溯这次全过程：读 [实测时间线](references/session-2026-10-10.md) 和 [来源清单](references/provenance.json)。历史版本、PID 和时延不代表当前状态。
- 修复后：执行 [本机验证与收尾](references/acceptance.md)，在本机完成检查并一次汇总。
- Computer Use skill 可见但缺独立 node_repl：读 [注册链修复](references/node-registration.md)，在本轮按条件补齐插件 MCP 声明；不需要另一次 Dot 验收。

## 执行流程

1. 记录北京时间和 UTC、原始错误、任务类型（本机 Codex / Dot 本地执行器）、应用与 CUA 构建版本。先读仓库规范和有效配置。用户只要求整理 Skill 时，不重新部署、重启应用或运行网页验收。
2. 用 `scripts/diagnose.py` 发现 MCP 配置与进程链，比较父子进程的指定环境变量。仅报告存在性/相等性，不输出凭证、签名身份、连接管道值或完整环境。
3. 集中核对四层信息：平台变量、任务/启动 cwd、自己的 Work 父连接信息、父子代理环境。同时区分 browser-only 的 cua_repl 与独立 Windows node_repl；若 skill 可见而独立工具缺失，核对插件是否已启用、既有 stdio 定义及插件根是否缺少 MCP 声明。按本次同类问题处理，不依赖 Dot 提供新测试记录。
4. 默认 `repair.py --fixes all` 一次预检、备份并安装 platform、cwd、browser、proxy 四层修复，各项按运行条件生效。用户明确限定单层才选子集。已有历史补丁先核对完整性，不重复覆盖。未知版本、不明修改或路径不符时保留文件并报告具体不兼容，不把旧补丁强套到新代码。
5. 修改前保存原文件和校验清单。cwd 桥保留原始 MCP 权限元数据；代理与 Work 连接信息只从同用户、指定 Codex 可执行文件的直接父进程继承。不修改 app.asar、系统 ACL、MXC 开关、签名校验或浏览器策略。
   若确认注册缺口，按注册链文档在同一次维修中追加 `node_registration.py` 的预览、安装和 `node_registration_probe.py` 检查；它不是 `--fixes all` 的子选项，只复用已存在且启用的配置。仅缺注册时不必重装已经正常的四层环境补丁。
6. 在本机完成文件/回滚哈希核对、父上下文检查、Node 语法检查和 MXC 启动验证。环境继承变化对新工具进程生效，`js_reset` 不会重启 MCP；不强杀主程序或无关会话。报告安装状态与实际验证范围。
7. 本机有可用且已加载修复的 CUA 时，可补做创建页、正文、跨调用复用、点击、返回、截图、清理；没有则以安装和本机检查收尾，说明未测项目。无需新建 Dot 验收任务，无需等待对方确认；不把可选网页自测变成用户继续配合的条件。
8. 恢复临时插桩，清理自建标签页与测试进程，核对回滚清单；分别报告改动、已验收能力和剩余问题。

## 实现边界

- 安装器只识别已记录的 **CUA 26.1007.21434** 原始指纹；当时桌面安装包为 26.1007.2314.0，两者不是同一版本字段。
- 2026-10-10 已有手工补丁会被识别并拒绝覆盖。继续排错用诊断脚本；确需改装先核对原维修目录的 `Restore.ps1` 与备份，不把已修改文件当原始基线。
- 新包脚本是参数化整理版，离线夹具测试不代表已在用户运行时部署。应用更新后重新发现版本，不能自动套旧补丁。
- `CUA_REPL_ENABLED_SURFACES=browser` 只限定 cua_repl，不证明独立 Windows node_repl 不受支持。后者是否提供须检查自己的注册链；不改变任何已禁用权限。空 apps 或空标签列表本身不是故障。
- 注册脚本仅支持 Computer Use 26.1007.21434，要求 Python 3.11+，拒绝未知 MCP 文件、未启用配置、任务身份或版本不符。桌面重启可能改变配置中的管道快照，刷新须提供上次事务清单；详见注册链文档。V2 返回 -32601 是未支持探测，不是验收通过。
- 不跳过网站检查，不把代理 HTTP 403 当作带身份检查通过，不用增大时限代替修复，不借其他任务管道冒充本任务。
- 此 Skill 不自动发送消息、重装、安装依赖或修改全局代理。缺少 CUA 工具时完成可执行的本机检查并说明范围，不要求用户转交任务，也不冒称网页自测已通过。
